# 第7回 クラウドコンピューティングと構成設計

## 今日の問い

> 何を自分で持ち、
> 何をクラウドや外部サービスに任せるべきか。

---

## 1. 自分の研究との関係

現在の研究システムは、どこで動作していますか。

例：

- 自分のPC
- 研究室PC
- 学内サーバ
- クラウド
- 外部サービス

---

| 構成要素 | ローカル維持 | クラウド候補 | 判断理由 |
|---|---|---|---|
|  |  |  |  |

---

## 3. 現時点の判断

クラウド化する価値が最も高い部分と、
ローカルに残すべき部分を1つずつ挙げてください。

---

## 4. 判断した理由

次の観点から説明してください。

- 初期・継続コスト
- 運用負荷
- 可用性
- 拡張性
- セキュリティ
- データ配置
- lock-in
- 開発速度

---

## 5. ディスカッションで気づいたこと

「全部クラウド」「全部ローカル」ではなく、
役割分担を考える上で気づいた点を記載してください。
