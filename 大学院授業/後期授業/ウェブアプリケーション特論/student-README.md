# Research Design Notebook

このディレクトリは、この授業で使用するResearch Design Notebookです。

## ファイル

### `research-map-before.md`

第1回に作成する研究システムの初期状態です。
第1回終了後は、原則として変更しません。

### `research-map.md`

授業を通じて更新するResearch System Mapです。

### `logs/`

各回のDesign Logです。

### `final-study.md`

最終成果であるTechnical Design Studyを整理するための文書です。

### `assets/`

Research MapやDesign Logで使用する図・画像等を置くためのディレクトリです。

## 基本方針

完成した文章を書く必要はありません。

授業時点での考え、判断、その理由、
ディスカッションで得た気づきを記録してください。

他の学生のNotebookは閲覧して構いませんが、編集しないでください。
