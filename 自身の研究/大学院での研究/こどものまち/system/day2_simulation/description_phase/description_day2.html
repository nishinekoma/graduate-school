クイズの やりかた 📝

これから、あやしい画面についての「クイズ」が出題されるよ！

💡 クイズの進め方

① 画面やカードをよく見て、どこがズルい罠（あやしい場所）か考えよう！

② 下にあるボタンの中から、「これが正しい！」と思う答えを選んで押して ね！

③ 正解すると、その罠の「くわしい解説」が見られるよ ね！

きみの おしごと 🚔
