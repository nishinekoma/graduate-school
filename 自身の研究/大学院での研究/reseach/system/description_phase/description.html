ゲームのコインではなく、ほんとうのお金かねがへってしまうんだ。

わるい表示ひょうじ（ダークパターン）とは？

インターネットには、ほんとうは買かうつもりがなかったのに、
つい買かってしまうように作つくられた罠わながあるよ。

⏳

「あと10秒！」と焦あせらせる

🔍

お金かねがかかることを
すごく小さく書かく

このように、きづかないうちに、いらないモノまで買かわせようとする
わるい罠わなを「ダークパターン」とよぶんだ。

ためしてみよう！（チュートリアル）

下のボタンのまわりに、ちいさな文字で書かかれたわるい罠わなが隠かくれているよ。
みつけたら、マウスでクリックしてみよう！

※毎月3,000円はらいます

🎉 大正解（だいせいかい）！

「無料むりょう」と大きく書かいてあるのに、
小さく「毎月まいつき3,000円えん」と書かいてあるね。
きづかずに押おすと、ずっとお金かねをはらうことになってしまうんだ。
これが「ダークパターン」の一ひとつだよ。

きみの おしごと 🚔

きみは今日から、わるい罠わなをみつける「ネットパトロール屋さん」だ！
